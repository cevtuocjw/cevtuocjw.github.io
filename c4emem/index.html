C4emem 是一个装在你电脑上的个人知识库 AI 助手。它不把内容传上云，检索、生成、主动提醒全部跑在本机。

WHY C4EMEM?(1) — (4)
(1).

数据不出本机

你的笔记、邮件、相册、健康数据都留在本地。检索用本机的全文索引（FTS5）＋本机嵌入模型，两条腿融合排序；只有你主动问它、且需要联网时，才走网络。

(2).

一个轮盘，管所有软件

桌面上的小东西不是装饰：鼠标放上去就展开一圈你正在开着的软件，敲字母直接切过去；全局快捷键 ⌥⌘C 随处呼出。右键是一张勾选清单，勾几个一起退掉。

(3).

它主动找你

不是"你问它才答"。它看你正在做什么（刚切到哪个软件、刚复制了什么），按你自己的规则决定要不要开口 —— 而且预算、间隔、静默时段都在你手里，吵到你了可以随手关掉。

(4).

对话就能长出功能

缺什么，直接跟它说。它会先给方案（不悄悄改代码），你点头之后功能才落地 —— 而且落在该落的地方：侧栏、来源扇区、设置、卡片，不是一个孤零零的入口。

OUR PHILOSOPHY

一个工具的价值不在于它能接多少服务，而在于它替你想到了什么。所以我们把两件事放到最重：它主动给你的东西，和它自己长大的能力。

每个来源都从"它到底是一份内容，还是一双手"开始判断 —— 分不清这两件事，就会答错"能不能接"。界面上每一个"我们做不到"，都会写成一句人话，而不是一个转圈。

EVERY FEATURE逐个说明

桌面 Pet · 轮盘

悬停展开、敲字母即开（C 是 Chrome）、打字筛选、中轴显示当前指着谁。切完自动收起，鼠标没挪开就不会再来烦你。

右键 · 勾选批量退出

列出正在运行的软件，勾几个一起退。退出是破坏性动作，所以按钮是红的、没勾时点不动，退完还会回来告诉你哪几个没退成。

检索 · 两条腿融合

全文索引（FTS5 trigram）＋向量相似度，用 RRF 融合。命中处开窗给你看上下文，点击弹全文，还能一键跳回那个软件。

主动式

检测在你机器上（零成本）、决策按你的规则、生成才花 token。每一条都能"处理了 / 略过"，勾过的会真的进下一次生成。

自我进化

跟它说想要什么 → 它读你本机装了哪些软件、推荐能做的功能 → 出方案 → 你点头 → 落地成真的功能。

来源扇区

左下角一颗按钮按 90° 扇出所有来源：Notion 四个库合成一格、邮件两条路合一、手机走 ADB。融合永远在正中最里那格。

PROACTIVE

它主动给你的东西，才是这个软件的核心。

  • 三层拆开：检测在你机器上做（不花一分钱）、决策走你的规则、只有真的要开口时才调模型。
  • 你说了算：最短间隔、每日预算、静默时段、哪一类只提醒一次 —— 全在设置里，随时关。
  • 待办板 ≠ 流水：待办的状态会被你改（处理了 / 略过），流水只增不改；两件事不混。
  • 勾了就真的算数：你标成"主动式"的功能，下一次生成时它会把你的勾选喂进提示词。

SELF-EVOLUTION

缺什么，跟它说；它长出来，长在对的地方。

  • 先出方案，再动代码：改配置（卸功能、标主动式）它可以直接做；改代码（新功能）必须先给你看方案。
  • 它知道你装了什么：每天自动重扫一次本机的应用清单 —— 你不用凭记忆敲软件名，它把候选摆出来。
  • 落在该落的地方：新功能会同时出现在侧栏、来源扇区、设置和卡片里，不是一个孤零零的入口。
  • 删除永远不静默：卸载进"待安装"保留 30 天，一键装回；内置功能只给"暂时关闭"—— 给"卸载"是在撒谎。

INSTALL

下载与安装（点开）macOS 13+
  1. 下载 Cevtuo C4emem.app（当前为内部构建，尚未公证签名）。
  2. 第一次打开如果被拦：右键 → 打开，或到「系统设置 → 隐私与安全性」里点"仍要打开"。
  3. 它会常驻菜单栏（C4），同时在桌面右下角放一个小家伙。
  4. 全局快捷键 ⌥⌘C / ⌥⌘4 随处呼出轮盘；鼠标放到小家伙上也会展开。

⚠️ 这是自用为主的软件：它读的是你自己电脑上的东西。第一次运行需要你填自己的来源凭据（Notion / 邮箱 / 手机等），不会带任何人的配置。

它是怎么跑的架构

一个本地 HTTP 核心（Bun，127.0.0.1:8770）＋ 一个很薄的 macOS 壳（Swift：菜单栏、窗口、桌面 Pet、网页↔原生桥）。

这样拆的好处：核心是纯 HTTP，手机端 / 小程序 / 别的壳都能复用；而原生只做"网页做不到的那几件事" —— 挪窗口、全局快捷键、把别人叫到前台。
