(1) 自我进化

按本机实际情况生成功能方案

功能由对话生成，落地位置由系统决定。以下为一次完整过程。

1读取本机状态

扫描已安装应用与已接入来源（含 Notion 各库），每日重新执行一次。该结果决定方案的作用范围。

2生成方案

输出功能描述与落点说明（侧栏、卡片或设置项），不产生代码改动。

3确认后执行

配置类变更（停用功能、标记为主动式）直接生效；代码类变更需先提交方案。两类变更分级处理。

4全位置生效

功能上线后同时出现在侧栏、来源面板、设置与卡片中，不限于单一入口。

5可回退

卸载的功能进入待安装列表，保留 30 天；内置功能仅支持暂时关闭。

(2) 主动式

检测 / 决策 / 生成三层分离

输出不受提问触发。

1检测层运行于本机

采集前台应用切换与剪贴板变更。该层不调用模型，不产生费用，数据不出本机。

2决策层按规则执行

仅当规则判定需要输出时才调用模型，调用次数与时机均可约束。

3频率可配置

最短间隔、每日上限、静默时段、单类提醒次数均为可配置项。

4标记参与生成

标记为主动式的功能会写入生成提示词。待办板（状态可变）与流水（只增）分表存储。

(3) 输入方式

语音 / 文字 / 结构流

语音

点击开始与结束。识别在本机完成，音频不外传；结果转为可编辑文本。

文字

直接输入。来源可切换，可连续追问；回答附带出处标注。

(4) 结构流

把一件要做的事
摊开成一张图

把任务表示为有向图：节点是块，边是类型化的数据与顺序关系。
块分四类：事件、来源、动作、去处。四类齐备即为一条可执行流程。

1放下一块事件：什么让这件事开始

手动触发、定时触发、应用切换、剪贴板变更、手机通知。

2接上一块来源：去看哪一份东西

笔记、邮件、手机通知流、Figma、剪贴板、网络检索。

3接上一块动作：让谁来做

总结、提问、查词 / 翻译。

4最后是去处：结论放到哪儿

写入货架、生成文件、写回 Notion、发送至手机、弹出通知。

5然后按运行

它按先后一块一块走完 —— 没填的块跳过，填好的照跑，不必等一张完美的图。

端口带类型，类型匹配方可连接。端口不设类型约束时，连线不表达任何语义。

三种视图

卡片：自由画布，坐标即位置。Nuggets：紧凑网格。3D：带厚度的投影。同一份图，三种呈现。

三种连线

实线：传递数据。虚线：仅表示先后，不传数据。点线：条件成立时执行。

部分执行

图不完整亦可运行：未填写的块跳过，已填写的正常执行。

(5) 它是怎么搭的

为什么这么拆

一个本地核心，加一层外壳。

核心为本地 HTTP 服务，监听 127.0.0.1:8770，承载检索、生成与主动式调度。
外壳负责菜单栏、窗口、桌面 Pet 与网页↔原生桥，仅实现网页环境无法完成的能力。

核心仅暴露 HTTP 接口，移动端、小程序与其它外壳可复用同一套实现；替换外壳不影响业务逻辑。

外壳为 macOS 原生实现（Swift），仅承担系统级能力。
核心为通用 HTTP 服务（Bun），与外壳解耦。

(6) 东西从哪来

一颗按钮，九个来源

来源集中管理。

已接入的来源集中于左下角面板：Notion、企业邮箱、企业微信邮件、Figma、飞书、手机。选择后导航栏按来源着色，当前来源可即时识别。

居中一项为「融合」：不限定来源，跨全部来源检索。来源过滤粒度可随时切换。

(7) 检索

这一件，值得讲细

关键词与语义双路检索。

检索的失效点通常不在召回，而在原始记录的表述与查询不一致。因此本系统并行执行两路检索，并融合排序。

1按词找

按字面命中，适用于记得原文片段的情形。结果为字面精确匹配。

2按意思找

按语义命中，适用于仅记得主题、字面完全不同的情形。索引与嵌入模型均在本机运行。

3两路合排，也各自留着手印

两路结果融合排序，并标注各自的命中路径，不合并为单一不可解释的分数。

4命中处开一扇窗

命中处展示上下文窗口，可展开全文，不直接交付整篇文档。

5一键回到它来的地方

结果可跳转回来源应用，检索到操作的路径不中断。

6它自己知道自己有多心虚

材料不足时标注低可信度，并提供联网检索选项；置信度不达标的内容不作结论输出。

索引基于本机语料构建。同一查询在不同设备上的结果互不相同，这是本地化存储的直接结果。

(8) 货架

什么都能先搁进去

暂存区。

右下角为暂存入口。内容采集时通常尚未确定用途，可先存入货架。多条内容可合并为一份材料，用于回答或作为结构流的一个块。

提供五种写入方式。以下每一格为该方式的完整操作记录。

文件拖入

从系统文件管理器拖入，保留文件名与类型。

图片拖入

生成缩略图，便于在列表中直接辨认。

⌘V 粘贴

读取剪贴板内容。输入框获得焦点时 ⌘V 保持为常规粘贴，不拦截。

选择后点按

不依赖元素类型、位置或浏览器实现：选中文本后点击入口即可写入。

设计
原则

工具的价值不由接入服务的数量决定，而由它在无提示条件下完成的工作量决定。

因此系统只有两项核心指标：主动产出的质量，与自我扩展的能力。其余均为其衍生物。

评估一个来源是否可接入时，须先区分它提供的是内容还是操作能力；两者混淆会导致判断错误。界面上所有未实现的能力均以明确文字说明，不以加载状态代替。

删除操作不静默执行。所有可删除对象均保留可回退路径。

安装

macOS 13+

下载与安装
  1. 下载 Cevtuo C4emem.app（当前为内部构建，尚未公证签名）。
  2. 首次启动如被系统拦截：右键 → 打开；或在「系统设置 → 隐私与安全性」中选择"仍要打开"。
  3. 应用常驻菜单栏（C4），并在桌面右下角显示 Pet 入口。
  4. 快捷键 ⌥⌘C / ⌥⌘4 可在任意界面呼出轮盘。

⚠️ 本软件读取本机数据。首次运行需自行填写来源凭据（Notion / 邮箱 / 手机等），安装包内不含任何他人配置。

下载 macOS 版（.dmg，约 50 MB）
离线可用范围
检索、记录、结构流与应用切换均可离线运行：索引与嵌入模型部署在本机。仅内容生成环节需要网络。
数据边界
核心仅监听 127.0.0.1，不对外暴露；页面与核心同源。所有内容默认留存于本机，仅在主动发起生成请求且确需网络时发出该次请求。
