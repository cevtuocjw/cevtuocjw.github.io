Two at a time

One machine-wide limit (BLQ_SLOTS, default 2). The rest queue by ticket, oldest first — late arrivals can never starve the ones already waiting.

Every window, one queue

Shells, editors and agents all share ~/.cache/blender-queue. No daemon, no config, no per-project setup.

Never the same job twice

If the same script is already running or queued, the new submission is skipped. Change the script — or pass --force — to run it again.

Strays get named

Headless Blender processes that bypassed the gate are listed with pid, CPU and elapsed time. blq kill-strays --yes stops them.

A status page that sleeps

It starts with the first job and exits after five idle minutes. When the tab is hidden it stops polling entirely — no more endless 3-second reloads.

One file, zero dependencies

Pure Python standard library. Read it, audit it, vendor it. MIT licensed.

Why a gate?

Nine jobs at once, each opening every thread it can find, do not finish faster. They finish slower — and they overwrite each other's output files along the way. A gate costs one line per command and turns the machine back into a predictable pipeline.

Installation

macOS & Linux · click to expand · 点开看安装步骤

1 · One line

  1. Run the installer: 
    curl -fsSL https://github.com/cevtuocjw/blendergate/releases/latest/download/install.sh | sh
    装到 ~/.local/bin/blq；用 BLQ_BIN=$HOME/bin 可以换目录。
  2. Make sure ~/.local/bin is in your PATH: 
    export PATH="$HOME/.local/bin:$PATH"
    安装脚本发现 PATH 里没有它时会提醒你。
  3. Verify: 
    blq --version
blq status

2 · Requirements

  1. Python 3.9+ — macOS system Python or Homebrew both work.
  2. Blender — detected at /Applications/Blender.app, ~/Applications/Blender.app, or on PATH. Override with BLENDER=/path/to/Blender.
  3. macOS or Linux. Windows is not supported yet (the queue relies on fcntl file locks).

3 · Manual install

  1. Download the single file: 
    curl -fsSL -o blq \
  https://github.com/cevtuocjw/blendergate/releases/latest/download/blq.py
chmod +x blq
mv blq ~/.local/bin/blq
  2. Or grab the tarball from the latest release.

4 · First run

  1. Queue a render instead of calling Blender directly: 
    blq render scripts/xxx.py -- --res 700
    -b --factory-startup -P 会自动带上。
  2. Open the live queue: 
    blq open      # http://127.0.0.1:8132/
  3. Uninstall: rm ~/.local/bin/blq and, if you want, rm -rf ~/.cache/blender-queue.
