01 — 它是什么

不是装饰，是一只手

它一直待在桌面上。鼠标放上去就摊开一圈，左边是你正在运行的软件 —— 点一个就把它叫到最前面， 连找 Dock 那一步都省了。右边是它自己的入口。

摸一下 → 一圈正在跑的软件摊开 → 敲首字母直接切过去

多 APP一整圈正在跑的软件

展开就是一整圈，按软件名的首字母敲一下就直接切过去 —— 全程不用碰鼠标。

只列真的在运行的那些：退掉的软件不会留在圈里（这一条专门验过）。

单个 APP只认一个软件

它就不展开那一圈了，点一下直接切过去。适合"一天就盯着一个东西用"。

常驻菜单栏 / Dock

两个开关自己挑。至少留一个 —— 两个都关掉就没有入口能把它叫回来了。

右键完整清单

右键点它，是完整的那个列表：勾几个、一起退掉。

02 — 它长什么样

六种形态，还有你自己造的

卡片 / 珍珠 / 银 / 铅 / 锌，加上你和它一起做出来的那些。每一种都能转，也都能定住。

依次换过去：卡片 → 珍珠 → 银（转）→ 银（不转）→ 锌 → 铅

转 / 不转一键定住，真的定住

⚠️ 这件事比看起来难：「银 / 铅 / 锌」原本是动图 WebP（无限循环）， CSS 停不掉它 —— 你把「不转」打开，它照转不误。现在这三种也走 3D，贴图只取一帧。

验收判据是像素：不转的那两张截图逐字节相同；而且还要证明"那不是一张空图"。

03 — 一起造一只新的

随便一张 2D 图 → 能转的真 3D；
或者直接给它一个模型文件

给它一张图，它抠掉背景、在本机算出这张图的深浅，然后重建成一只可以转的立体。 不是把同一张图叠几层那种"假厚度"。
手上有现成的模型？把 .glb / .gltf / .fbx / .usdz 拖进来就是一只 —— 模型本来就是 3D，传完直接能用，不用再算什么。

选一张图 → 抠底 → 量深度（约 4 秒）→ 预览里那一只已经在转 → 起个名字装上去

四个入口怎么给都行

⌘V 直接粘贴（截图之后最顺手）· 把文件拖到窗口任何地方 · 点「选文件」· 贴一个网址（直接给图片地址也认，没写 https:// 会自动补）。

抠底抠不动就不抠，不会卡住

本来就是透明底的直接用；背景太杂抠不动 ⇒ 原样不抠照样能做 3D。 只有"连图都读不动"才算失败。

模型文件glb / gltf / fbx / usdz / obj 直接就是一只

拖进来、或者贴一个模型的网址（服务端去取，页面不用管跨域）。 没有"再做出来"那一步 —— 传完预览里已经在转，名字默认取文件名。

压缩包下载来的 .zip / .rar 直接拖进来

不用自己解压、不用自己挑文件。App 会自己一路拆到底（最多三层）。 已经拿真包验过的三种形状：

zip → rar，模型是 fbx，贴图在外面 · zip → zip，模型是 obj + mtl · zip → rar，模型是 obj、没有 mtl。

里面的 .obj 会在本机转成 GLB，并且把颜色贴图烤进文件里 —— 于是"贴图找不到"这一类问题整个消失。

没有 .mtl颜色是我们自己认出来的

有些包（比如那个汉堡）里根本没有 .mtl —— .obj 里那句 mtllib Burger.mtl 指向一个不存在的文件。那样旧版会渲染成灰白模型， 而且一个错都不报。

现在按名字自己认：*_BaseColor / *_Albedo / *_Diffuse / *_Color 加分， *_Normal / *_Roughness / *_Metallic / *_AO / *_ORM 减分，同分取体量大的那张。

⚠️ 判据不是"挑到了没有"，是挑对没有：包里的图看着全是法线那一类时， 宁可不贴（把法线图当颜色贴上去，整只会比灰白更糟），并把这句话如实说出来。

不浪费只把用得到的图烤进去

包里常常带一整套 PBR 贴图，而只有颜色那张真的用得上。 只烤真正引用到的那几张 —— 实测汉堡那只 18.1MB → 12.3MB。

另外 .gltf（JSON 那种）的顶点数据在另一个 .bin 文件里， 它也一起存下来，否则模型载不进来。

全离线深度是在你机器上算的

用的是 Depth Anything V2 (Small) 的 ONNX 版 + onnxruntime(WASM) + three.js， 34MB 已经打进包里。一张图约 4 秒，不联网、不上传任何东西。

老的那些一键补成 3D

在 3D 这条路做出来之前做的宠物，列表里会多一个「做成 3D」按钮，点一下就补上。

看哪儿抬起头来，能看见顶面

以前它只绕竖轴转，不论怎么转都看不到上面。现在设置里多了一个「看哪儿」滑杆 （0° 平视 → 60° 高俯），一边转一边就能抬头。

抬头之后相机自动退远 —— 否则上下两条边会被切掉，而那不会报错。

列表每一格是它自己的样子

以前模型那一格垫的是一张通用卡片，于是蘑菇 / 兰花 / 披萨在列表里长得一模一样。 现在每一格是真渲染出来的缩略图（老的那些会自动补拍）。

04 — 安装

两步

安装说明（点开／收起）
  1. 下载上面那个 .dmg，打开，把 CEVTUO-PET 拖进「应用程序」。
  2. 第一次打开会被 Gatekeeper 拦一下（没做开发者签名）。右键点它 → 打开， 再确认一次就好；之后双击就行。
  3. 它在菜单栏有一颗图标（一枚圈 + 一朵小花）；设置页从那里进。
  4. 要用"跟它说 / 造一只新的"这些功能，得填你自己的 API key —— 设置页里那一栏。key 只存在你自己的 ~/.c4emem/，不进包、不上传。
和 Cevtuo C4emem 共用同一个引擎和同一份数据。两个一起用没问题 —— 它们会复用同一个后台进程，不会互相抢库。
